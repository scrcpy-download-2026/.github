📱 **scrcpy** is a free, open-source application that lets you display and control an Android device from a Windows PC, macOS computer, or Linux system. It mirrors your Android screen in a desktop window and lets you interact with your phone using a mouse and keyboard.

⚡ With scrcpy, you can control your Android phone from your computer, type using a physical keyboard, interact with mobile apps, and transfer control through a USB or supported wireless connection. ## 🛠️ Installation Instructions

### Method 1: Windows

1. ⬇️ Download a Windows-compatible scrcpy release from a trusted source.
2. 📦 Extract the archive to a folder on your computer.
3. 📱 On your Android device, open Developer Options and enable USB debugging.
4. 🔌 Connect your phone to the computer with a data-capable USB cable.
5. ✅ Unlock your phone and accept the USB debugging authorization prompt.
6. 🚀 Run the appropriate scrcpy executable in the extracted folder.

### Method 2: Wireless Connection

3. 🔗 Establish the ADB connection according to the official scrcpy instructions.
4. 🚀 Start scrcpy after the device is detected.
5. 📡 Keep the device and computer connected to the required network when using a network-based connection.

Wireless setup steps differ depending on Android version and connection method. Follow the official documentation rather than assuming every device uses the same procedure.

## 🧰 Troubleshooting

### scrcpy Does Not Detect My Android Device

- 🔌 Check that your USB cable supports data transfer, not just charging.
- 📱 Make sure USB debugging is enabled in Developer Options.
- 🔐 Unlock your phone and accept the authorization prompt.
- 🛠️ Follow the official ADB troubleshooting instructions if the device is still missing.

### The Android Screen Does Not Appear

- 🔄 Disconnect and reconnect the device.
- 📱 Confirm that the device is unlocked and authorized.
- 🧩 Make sure you are using a compatible scrcpy package.
- 📚 Check the terminal output for connection or configuration errors.

### Wireless Connection Is Not Working

- 🌐 Verify the required network and debugging settings.
- 🔗 Follow the correct pairing or ADB connection procedure for your Android version.
- 🛡️ Check firewall settings if the connection is blocked.
- 📚 Consult the official documentation for the supported wireless workflow.

### Mouse or Keyboard Control Does Not Work

- 📱 Check that the device is connected and authorized.
- 🧩 Review any command-line options that may affect input control.
- 🔄 Restart scrcpy and reconnect the device.
- 📚 Check the documentation for device-specific limitations.

### The Application Closes Immediately

- 📦 Make sure the archive was extracted completely.
- 🖥️ Confirm that you downloaded the correct package for your operating system.
- 🛠️ Run scrcpy from a terminal to inspect any error output.
- 📥 Download a fresh release from the official repository if the package appears damaged.
